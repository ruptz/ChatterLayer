    Type the name of any font installed on this PC. Fonts that aren’t installed, or that co-streamers don’t have, go in the fonts folder (.ttf, .otf, .woff, .woff2). The overlay serves them itself, and each one’s name is its file name without the extension.

    Custom CSS

    Applied after everything above, so it wins. Each line is a .caption holding .speaker and .text; .caption.partial is text still being spoken, and .caption[data-user="<Discord ID>"] picks out one person. --color is the speaker’s colour. Web fonts load with @import, but only while OBS is online. A co-streamer can drop yours by adding &css=0 to their link.

    Share with co-streamers

    Opens a Cloudflare tunnel so everyone co-streaming can point OBS at one link, instead of each running their own bot and speech model. Nothing leaves this PC until you press Start, and the tunnel is always closed again when ChatterLayer starts.

    Link to share
    —

    The link carries an access key. Without it the page returns 401, so a guessed tunnel address gets nothing.

    Each streamer can size the overlay for their own scene by adding &size=42, &hold=5 (seconds), &lines=2, &partials=0, &names=0, &pos=top or &align=center to their copy of the link. Those beat the settings in Output and Style for that one browser source only.

    Keep slurs off the stream

    Racial and ethnic slurs are replaced with ***** in both speech and speaker names. Whole words only, so ordinary speech isn’t mangled.
