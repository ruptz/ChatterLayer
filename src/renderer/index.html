    Remote overlay

    Off

    Opens a Cloudflare tunnel so everyone co-streaming can point OBS at one link, instead of each running their own bot and speech model. Nothing leaves this machine until you press Start, and the tunnel is always closed again when ChatterLayer starts up.

    Link to share —

    The link carries an access key — without it the page returns 401, so a guessed tunnel address gets nothing.

    Each streamer can size the overlay for their own scene by adding &size=42, &hold=5 (seconds), &lines=2, &partials=0 or &names=0 to their copy of the link. Those beat the sliders above for that one browser source only.
